## 📦 Install

**One command (installs the whole collection):**

```bash
curl -fsSL https://raw.githubusercontent.com/milad-ahmd/agent-skills/main/install.sh | bash -s -- tiktok-viral-creator
```

**Manually (Claude Code):**

```bash
git clone https://github.com/milad-ahmd/tiktok-viral-creator /tmp/tiktok-viral-creator
mkdir -p ~/.claude/skills && cp -r /tmp/tiktok-viral-creator/skills/tiktok-viral-creator ~/.claude/skills/
```

**Per project:** copy `skills/tiktok-viral-creator` into `<project>/.claude/skills/`.
**Any other agent:** paste [`SKILL.md`](skills/tiktok-viral-creator/SKILL.md) into your rules or system prompt.
